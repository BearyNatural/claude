First time you open it

  • Windows: run the .exe. It isn’t code-signed yet, so Windows may say “Windows protected your PC” — choose More info › Run anyway.
  • Mac (Apple silicon): open the .dmg, drag Geranium to Applications, then right-click it › Open the first time.
  • Linux: the .deb is recommended on Debian and Ubuntu (sudo apt install ./Geranium-….deb). The .AppImage runs anywhere after chmod +x.

The desktop app and the browser version are separate: each keeps its own encrypted data. Move data between them with an encrypted backup (Backup & restore).
